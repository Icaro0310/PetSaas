Política de Privacidade - PetCare

Última atualização: 27 de agosto de 2026

A PetCare respeita a privacidade dos utilizadores. Esta política descreve que dados recolhemos, como os usamos e como os protegemos.

1. Dados recolhidos

  • Dados de conta: e-mail, nome e identificador de utilizador, fornecidos através do Supabase Auth.
  • Dados dos pets: nome, espécie, raça, fotos, histórico médico, medicações e doses.
  • Dados de cuidadores: e-mail dos convidados e permissões atribuídas.
  • Dados de localização: opcionais, apenas quando um finder partilha a localização do animal encontrado.
  • Token FCM: para notificações push, com consentimento do dispositivo.

2. Finalidade do tratamento

Os dados são utilizados exclusivamente para:

  • Gerir o perfil e os animais de estimação;
  • Lembrar doses de medicação;
  • Permitir que terceiros contactem o dono se encontrarem o pet perdido, sem revelar dados pessoais;
  • Enviar notificações de rotina.

3. Partilha de dados

Não vendemos, alugamos ou partilhamos dados pessoais com terceiros para fins comerciais. A página pública do QR Code mostra apenas informações não identificáveis do pet, nunca do dono.

4. Segurança

Utilizamos Row Level Security (RLS) na base de dados Supabase, autenticação por magic link, ligações encriptadas (HTTPS/TLS) e acesso restrito a cuidadores convidados.

5. Direitos do utilizador

Pode aceder, corrigir ou eliminar os seus dados a qualquer momento na aplicação. Para eliminar a conta definitivamente, contacte-nos.

6. Provedores de serviços

Utilizamos Supabase (base de dados, auth, storage), Firebase (notificações e analytics) e Cloudflare (hospedagem web).

7. Contacto

Para questões sobre privacidade, contacte privacidade@petsaas.pt.
