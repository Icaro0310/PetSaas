Politica de Privacidade - PetCare

Ultima atualizacao: 02 de setembro de 2026

1. Introducao

O PetCare ("Servico", "nos", "nosso") respeita a sua privacidade. Esta Politica de Privacidade descreve como recolhemos, usamos, compartilhamos e protegemos os seus dados pessoais.

Estamos em conformidade com:

  • Lei Geral de Protecao de Dados (LGPD) - Lei n. 13.709/2018 (Brasil)
  • California Consumer Privacy Act (CCPA) - Cal. Civ. Code 1798.100
  • Regulamento Geral de Protecao de Dados (RGPD/GDPR) - Regulamento (UE) 2016/679
  • Lei n. 23/96, de 26 de julho (Portugal)

2. Dados Recolhidos

2.1 Dados de conta

  • Nome completo
  • Email
  • Numero de telefone (opcional)
  • ID de utilizador (Clerk user ID, formato: user_xxx)

2.2 Dados do pet

  • Nome do pet, especie e raca
  • Foto do pet
  • Peso, descricao
  • Informacoes de emergencia (alergias, medicacoes criticas, avisos)
  • Numero de microchip
  • QR Code UUID (identificador publico unico)

2.3 Dados de medicacao

  • Nome do medicamento, tipo, dosagem, horarios
  • Historico de doses administradas
  • Identificacao de quem administrou cada dose (owner_id ou caregiver_id)

2.4 Dados do dispositivo

  • Device ID (identificador do dispositivo)
  • FCM Token (Firebase Cloud Messaging, para push notifications)
  • Sistema operativo (Android/Web)

2.5 Dados tecnicos

  • Endereco IP (recolhido automaticamente pelo Supabase)
  • User agent (browser/app version)
  • Dados de analytics (PostHog, Firebase Analytics): eventos de uso, sessoes, timestamps

2.6 Dados de localizacao

Localizacao aproximada (latitude/longitude) - apenas quando o utilizador envia uma mensagem "encontrei um pet" via QR Code, e apenas se o utilizador conceder permissao explicita.

4. Compartilhamento de Dados

4.1 Provedores de servico

  • Supabase (backend, base de dados, storage)
  • Clerk (autenticacao)
  • Firebase / Google (analytics, crashlytics, FCM)
  • PostHog (analytics)
  • Sentry (monitoramento de erros)
  • Netlify (hosting web)
  • MailerSend (envio de emails)

4.2 Dados publicos via QR Code

Quando um pet e registado, e gerado um QR Code unico. Se alguem escanear o QR Code, ve APENAS: nome do pet, especie, raca, foto, descricao, info de emergencia, alergias, meds criticas, avisos, microchip, status is_lost. NUNCA ve: owner_id, email, telefone, endereco, ou historico de doses.

5. Direitos do Utilizador (LGPD + CCPA + GDPR)

  • Confirmacao da existencia de tratamento
  • Acesso aos dados
  • Correcao de dados incompletos, inexatos ou desatualizados
  • Anonimizacao, bloqueio ou eliminacao de dados desnecessarios/excessivos
  • Portabilidade dos dados (exportacao em formato estruturado)
  • Eliminacao dos dados pessoais tratados com consentimento
  • Informacao sobre compartilhamento com terceiros
  • Revogacao do consentimento

Exclusao de conta: Disponivel em "Perfil > Excluir conta (LGPD)". A exclusao apaga FISICAMENTE todos os dados. A acao e IRREVERSIVEL.

Como exercer os direitos: Envie email para legal@petcare.com com assunto "Exercicio de direitos - LGPD/GDPR/CCPA". Responderemos em ate 15 dias (LGPD) / 30 dias (CCPA) / 1 mes (GDPR).

6. CCPA - Direitos Especificos (California)

  • Nao vendemos os seus dados pessoais. Nao ha "Do Not Sell My Personal Information" aplicavel.
  • Direito de saber (CCPA 1798.110): Pode solicitar as categorias e pecas especificas de dados pessoais recolhidos.
  • Direito de excluir (CCPA 1798.105): Pode solicitar a exclusao dos dados pessoais.
  • Direito de nao discriminacao (CCPA 1798.125): Nao discriminaremos por exercer os seus direitos CCPA.

7. Retencao de Dados

  • Dados da conta: Retidos enquanto a conta estiver ativa. Excluidos em ate 30 dias apos pedido.
  • Dados de analytics: 13 meses (PostHog) / 14 meses (Firebase Analytics).
  • Logs de erro (Sentry): 90 dias.
  • Backups: Supabase mantem backups diarios por 7 dias (plano Free).

8. Seguranca

  • Criptografia: Dados em transito via HTTPS/TLS 1.2+. Dados em repouso cifrados pelo Supabase (AES-256).
  • RLS (Row Level Security): Todas as 9 tabelas tem RLS ativo. Cada utilizador so pode acessar os SEUS dados.
  • Chaves: Apenas chaves publicas (anon/publishable) no cliente. Chaves secretas NUNCA no frontend.

9. Transferencia Internacional de Dados

Os dados podem ser processados em Uniao Europeia (Supabase Frankfurt, PostHog EU, Sentry EU), Estados Unidos (Firebase/Google, Clerk) e Brasil. Transferencias fora da UE/EEE sao feitas com Clausulas Contratuais Padrao (GDPR Art. 46).

10. Cookies e Tecnologias Similares

O PetCare Web utiliza cookies essenciais para o funcionamento (sessao de autenticacao via Clerk). Analytics (PostHog) utiliza cookies/anonimizacao para rastrear eventos. Nao utilizamos cookies de publicidade de terceiros.

11. Notificacoes Push

O PetCare envia notificacoes push (FCM) para doses pendentes/perdidas, mensagens de "pet encontrado" e lembretes. O utilizador pode desativar nas configuracoes do dispositivo. O FCM Token e removido quando a conta e excluida.

12. Menores

O Servico nao e direcionado a menores de 16 anos. Nao recolhemos intencionalmente dados de menores. Se descobrirmos dados de menor, serao excluidos imediatamente.

13. Alteracoes a esta Politica

Podemos atualizar esta Politica a qualquer momento. Notificaremos os utilizadores por email e/ou na aplicacao com pelo menos 30 dias de antecedencia para mudancas materiais.
